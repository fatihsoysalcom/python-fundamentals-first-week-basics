# Python Fundamentals First Week Basics

This example demonstrates fundamental Python concepts suitable for a beginner's first week of learning. It covers basic output using `print()`, variable assignment with different data types (integers, strings, lists), simple arithmetic and string operations, conditional logic with `if/else`, iteration using a `for` loop, and defining/calling a basic function. The code highlights Python's readable and simple syntax.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Open a terminal or command prompt.
3. Navigate to the directory where you saved `main.py`.
4. Run the script using `python main.py`.
